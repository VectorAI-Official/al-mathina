# Banner Image Setup

## Instructions:

1. Save your banner image as `banner.png` in this directory (`flutter_preview/assets/images/`)
2. The image should ideally be 800x400 pixels (or maintain a 2:1 aspect ratio)
3. Supported formats: PNG, JPG, JPEG

## Current Banner:
- File: `banner.png`
- Expected dimensions: 800x400 (2:1 aspect ratio)
- The banner will be displayed on the home page below the search bar

## To add the banner:
1. Download/save your banner image
2. Rename it to `banner.png`
3. Place it in this folder: `flutter_preview/assets/images/`
4. Run `flutter pub get` to ensure assets are recognized
5. Hot reload or restart your Flutter app

The app is already configured to display the banner image from this location!
